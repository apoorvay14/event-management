# Event Booking & Management System

A full-stack web application designed to simplify event creation, management, and booking, with automated deployment using cloud and DevOps practices.

## 🎯 Problem Statement & Objective

Managing events and user bookings manually can be inefficient and difficult to scale. This project aims to provide a centralized platform where administrators can manage events while users can browse available events and make bookings.

## 🏗️ Solution Overview

The application combines a web-based frontend, backend APIs, database services, and an automated CI/CD pipeline to provide an end-to-end event management and deployment workflow.

## ✨ Features

* Event creation and management
* User event booking
* REST API-based backend
* Database integration
* Containerized application deployment
* Automated CI/CD pipeline

## 🛠️ Tech Stack

**Frontend:** HTML, CSS, JavaScript
**Backend:** Node.js
**Database:** MongoDB
**DevOps & Cloud:** Jenkins, Docker, AWS, Ansible
**Version Control:** Git, GitHub

## 🔄 CI/CD Workflow

The project uses an automated deployment workflow:

**GitHub → Jenkins → Docker → AWS → Deployment**

Code changes pushed to GitHub trigger the pipeline, which builds and containerizes the application before deploying the updated application to AWS.

## 📌 Project Highlights

* Built a full-stack event management application.
* Implemented automated CI/CD using Jenkins and GitHub.
* Used Docker for application containerization.
* Integrated AWS for cloud deployment.
* Used Ansible to automate deployment tasks.
